## Default Permission

Everything the page needs to drive the native tab bar.

#### This default permission set includes the following:

- `allow-show`
- `allow-set-selected`
- `allow-set-hidden`
- `allow-set-badge`
- `allow-set-tint`
- `allow-register-listener`
- `allow-remove-listener`
